## 这是一个什么项目

**一个会看你打游戏、会记事、能和同类对话的桌面宠物**

继承了原版绝大部分的功能，同时运行让模型自己选择动画、爬取表情包（图源自：[爱梗图](https://aigengtu.com/)）的能力，加入游戏日志和游戏机制描述文件的读取能力，可以独立管理记忆。

## 安装

### 前置

- 已装好 **DeepSeek Harness**（桌面端或 `dsh web` 均可）
- 能读截图的**多模态模型**（默认跟随 DSH 会话模型）

### 从本仓库安装

```sh
git clone https://github.com/SCP173JThePeanut/dsh-game-pet-watch
cd dsh-game-pet-watch
npm pack                                   # 生成 dsh-game-pet-watch-<版本>.tgz
```

然后二选一：

```sh
# ① 命令行（dsh web 用户用 --profile web）
dsh plugin --profile desktop add ./dsh-game-pet-watch-1.4.0.tgz

# ② 桌面端：应用内「插件管理」→ 安装 → 选上面那个 .tgz
```

装完**重启 DSH**。第一次启动会自动拉起桌宠，用户数据落在 `~/.dsh/dsh-pet-gpw`。

### 装完你会看到

- 桌面角落出现一只鱼（默认尺寸/位置在设置页可改）
- 右上角一颗状态胶囊：`观察中 · N` / `已暂停` / `插件离线`
- 右键宠物 → **记录网页**，能打开聊天记录；右键 → 观察面板看状态/记忆/提示词

### 卸载

```sh
dsh plugin --profile desktop remove dsh-game-pet-watch
```

## ⭐ 相对原版新增的功能

### 1. 看画面说话（"大脑"）

定时截一张游戏窗口（或整屏），连同记忆与人设交给多模态模型，模型只回两种结果：

```
SILENT                                  ← 不输出
{"say":"台词","anim":"动画名","img":"表情包名","remember":"要长期记住的一句话"}
```

- 规则写在提示词里，默认：Boss / 残血 / 死亡 / 稀有掉落 / 升级 / 卡关 / 长时间没动 / 主人开口 —— 其余时间一律安静
- **空闲退避**：键鼠静止 + 游戏里长时间没事件时，观察间隔自动翻倍，减少 API 调用次数

### 2. 游戏事件 → 立刻反应

- 支持任意"一行一条 JSON"的事件文件，或挂一个采集器脚本把游戏日志转成事件
- 重要事件（夺旗 / 失旗 / 增援 / 连杀…）**不等下一拍**，立刻单独说一句
- 双重限流：**冷却 30 秒** + **每 10 分钟最多 8 次**（都可调，0 = 不限），超了只把事件留在上下文里

### 3. 记忆（短期 → 长期）

- 短期窗口（默认 12 条）+ 攒够 10 条自动压成长期要点（上限 2400 字）
- 模型可以自己往长期记忆里 **加入重要事件**（`remember` 字段）——重要约定不会随上下文窗口滑走
- 压缩时强制保留它的口癖与身份设定；面板里也能手改长期记忆 / 加备注

### 4. 多鱼支持

- 暂时只能开两条
- 每条鱼各自一份：**记忆 / 人设 / 提示词 / 端口 / QQ 账号 / 观察状态**

### 5. 鱼板网络与记录网页

- 多条鱼互相看得见：谁说了什么会进彼此的时间线，也会被带进下一轮上下文
- 记录页 `<插件地址>/game-pet-watch/history`、群记录页 `/game-pet-watch/qq`（不依赖 DSH 前端）
- 桌宠右键 →「记录网页」直接打开，**不用记端口**（DSH 每次重启端口都会变，插件靠登记簿自愈）
- 跨来源去重（同一句话不再显示两遍）、系统条目可隐藏

### 6. 表情包图库

- 从图源抓梗图 → 视觉模型逐张写描述 → 进图库缓存，之后**离线可挑**
- 每条鱼只认自己名下描述过的图，避免两只鱼互相污染
- 模型在 `img` 字段里点名字，名字不在图库里就丢弃（不配图，也不报错）
- 支持 **png / webp / gif / jpg**：直接把 `.gif` 丢进 `~/.dsh/dsh-pet-gpw/memes/`，气泡里正常播放
- **QQ 群收图不再转成 PNG**（以前转一次动画就没了）：gif 原样存 `.gif`；扩展名清单在
  `src/images.js` 的 `MEME_EXTS`，扫描器 / 入库 / 导出网页 / 副本图片路由共用同一份

### 7. 思考与接话

- **思考档位**（`modelThinking`）：`off / low / medium / high / max`，空 = 跟随模型默认。
  可选值是模型自己声明的（`GET /model-info` 能查），填了不支持的值会自动退回默认，不会把请求打挂。
- **接话**（`chainMax`，0–8，默认 2）：模型说完一句后，可以调用 `speak_again` 工具**再调用一次自己**接着说下一句。
  - 每一句仍然**只输出一个 JSON**（不会变成数组，解析层不用容错）
  - 每次接话都是**一次独立请求**（system 不变，只带上"你上一条说了什么、还剩几次"）
  - 剩余次数写在提示词里（每轮提示还会再报一次），次数用完就拒绝
  - 后续几句按 0.9 秒间隔补投到气泡，动画只在第一句播

### 8. 桌面副本的界面

| 交互 | 行为 |
| --- | --- |
| 鼠标扫过宠物 | 浮出输入框，回车即问（答案仍走气泡） |
| 右键 | 「记录网页」子菜单 / 碎碎念 / 对话 / 改名字 / 游戏情况 / 机制库 / 重载配置 |
| 状态胶囊 | 右上角 `观察中 · 52` / `已暂停` / `插件离线`，点它开观察面板 |
| 观察面板 | 状态 / 记录 / 提示词三页签，可改可清 |

## 常用配置

DSH 左下角设置页里调整（也可以写 `config.json`）：

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `intervalSec` | 60 | 多久看一次画面 |
| `cooldownSec` | 25 | 两次自动开口的最短间隔 |
| `gohImmediateCooldownSec` | 30 | 游戏事件的反应冷却 |
| `gohReactionBudget` | 8 | 每 10 分钟最多因事件主动说几次（0 = 不限） |
| `memoryRecentTurns` | 12 | 短期记忆带多少条 |
| `compactEvery` | 10 | 攒够多少条压成长期记忆 |
| `memoryLongTermChars` | 2400 | 长期记忆字数上限 |
| `memoryAllowSelfNote` | 开 | 允许模型自己记长期记忆 |
| `collidePushPx` | 3 | 撞开力度（0 = 只冒话不推） |
| `historyHideSystem` | 开 | 记录页是否隐藏系统条目 |
| `modelThinking` | 空 | 思考档位（空 = 跟随模型默认；可选值由模型声明） |
| `chainMax` | 2 | 接话次数上限（0 = 关，每接一次多一次模型调用） |
| `gpwRoot` | 空 | 桌宠目录；留空就用包内的 `pet/` |

游戏事件文件、机制库路径由**你自己填**：插件不绑定任何一款游戏，也不预置内容。

## 已知限制

- 目前只能调用 DSH 的 Deepseek V4.1 Flash API
- 游戏事件需要你自己提供事件文件或采集器；不填就只有"看画面"这一条路
- 端口随 DSH 重启变化：插件靠 `~/.dsh/fish-board/registry.json` 获取端口
